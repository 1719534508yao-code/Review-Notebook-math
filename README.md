# 试卷错题整理（数学版）

把做过的数学试卷 PDF 丢进来 → 自动按题号切成小题图片 → 你点出哪几道错了 →
AI 识别每题的题型和知识点 → 错题进错题本、对题进题库，**同时在你电脑的文件夹里排好** →
自动生成知识点气泡图和每周总结。

全程本地运行，数据只存在你自己的电脑上，不联网上传（只有「AI 识别」这一步会把你**选的切片图**发给模型厂商）。

---

## 一、启动

**最简单：在 Finder 里双击项目根目录的 `启动试卷整理.command`。**

也可以在终端里跑：

```bash
cd /Users/yao/ai程序库/试卷集
./run.sh
```

- 首次运行会自动建虚拟环境、装依赖（约 1~2 分钟），之后启动只要几秒。
- 启动完成后**浏览器会自动打开** <http://127.0.0.1:8000>。
- 想停止：回到启动它的那个终端窗口，按 `Ctrl+C`。关掉窗口也行。
- 8000 端口被别的程序占用时会自动顺延到 8001、8002…并打开对应地址。
  重复双击不会启动第二个实例，只会帮你打开已经在跑的那个。

> 前提：macOS 自带 Python 3 即可，不需要装别的东西。

## 二、上传流程（一次大约 2 分钟）

### 1. 上传并切片（「上传」页）

1. 选试卷 PDF（**文字版**，即能在预览里选中文字的那种；扫描件不行）。
2. **手选** 年份 / 城区 / 考试类型。软件会记住你上次的选择，连续传同一个区的卷子只需要换文件。
3. 点「上传并切片」。

软件会按题号把整卷切成一张张小题图片，然后自动跳到「复核」页。

> **上传页下方就是「📊 已上传的卷子」汇总**：把你传过的所有卷子按
> **科目 → 年份 → 考试类型 → 城区** 排成一棵目录树，每行一条横条表示它下面的题量，
> 右侧直接写着套数和题数。点某一行卷子会跳到「复核」页并选中它。
> 只列出**真的传过**的年份/类型/城区，没传过的不占位置。
> 每行卷子右侧还有一个 **🗑（鼠标移上去才显示）＝ 删除整套卷**，
> 方便传错卷子时一键清掉。

### 2. 复核（「复核」页）—— 这一步决定哪些进错题本

- 每道题一张卡片，显示切片缩略图。
- **点一下缩略图 = 标为错题**（卡片出现红框和「✗ 错题」），**再点一下取消**。标完立即保存。
- 没点的题一律算作**做对了**。
- 如果某题切片不对（比如题目跨页没接好），可以展开卡片里的原文核对。
- **数学卷一律 21 题**（软件已按这条规则设置）：正常卷子不会多出第 22 题。
  万一软件真的切出了第 22 题，它不会偷偷扔掉，而是**保留并在页面顶部提醒你复核**
  （可能是把答案段的编号误当题号了）。中间某题没切出来（「题号 N 未定位」）同样会提示。

### 3. 点「确认无误，开始识别」

会弹一个确认框告诉你要删源 PDF、错题几道、正确题几道。确认后：

- AI 开始逐题识别（一串进度提示，22 题约 2 分钟）。
- **源 PDF 在这时被删除** —— 软件只保留切片，这是设计如此（见下方「归档目录」）。

### 4. 识别完自动刷新

识别完成后卡片会上锁（表示已归档）。少数题 AI 会**主动弃权**（它觉得没把握），
这类题会留空并保持可编辑，你手动补一个题型/知识点即可 —— 补完立刻归档。

> **如果识别中途弹出「API 额度/余额不足」或「Key 无效」**：整卷会立即停下（不会继续白花钱），
> 已经打好的标签保留。处理完 key 的问题后点「重试识别」继续，只会补做没打标的题。

## 三、AI 识别的 API Key（可选）

**不配 key 也完全能用。** 没有 key 时软件进入「手动模式」：复核页每张卡片上有
**题型**和**主知识点**两个下拉，你逐题选一下，效果和 AI 打标完全一样，只是要自己点
（选完立即归档）。适合卷子不多、或者想先试试软件的情况。

想开 AI 自动识别，按下面做一次就行：

1. 到模型厂商申请一个能**识图**的 API Key：
   - **智谱 GLM-4V**（当前配置，更便宜）：<https://open.bigmodel.cn> → 创建 API Key
   - **阿里云百炼**（通义 Qwen-VL-Max，设计原定方案）：<https://bailian.console.aliyun.com> → 开通百炼 → 创建 API Key
2. 在项目根目录把 `.env.example` 复制成 `.env`（文件名就叫 `.env`，前面有个点）。
3. 按你选的那家填好，例如用智谱：

   ```
   VLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
   VLM_MODEL=glm-4v-plus
   VLM_API_KEY=你申请到的key
   ```

   用阿里云百炼则填：

   ```
   VLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
   VLM_MODEL=qwen-vl-max
   VLM_API_KEY=你申请到的key
   ```

4. **重启软件**（关掉启动窗口再双击一次）。

**费用**：一套 22 题的卷子约 **¥1**（智谱 glm-4v-plus 实测约 12 万 token/套，2 分钟）。
`.env` 里的注释写了其它更便宜/更贵的模型选项和实测对比。

> 关于识别准确率，请**务必知道**：知识点（尤其是有 96 个近义叶子时）AI 判得**不算准**，
> 实测主知识点判对约六成、题型判对接近十成。所以复核页每张卡片都留了手动改的下拉 ——
> **AI 建议 + 你一眼扫过去改几个**才是正确的用法，别指望它全对。

## 四、归档目录（Finder 里直接可逛）

所有切片都实打实落到 `archive/` 文件夹，**和软件里看到的是同一批文件**，
可以随时用 Finder 打开、拖走、备份。

```
archive/数学/
├── 题库/                     ← 做对的题
│   └── {年份}/{城区}/{考试类型}/
│       └── {题号}_{题型}.png      例：题库/2022/朝阳区/期末/7_选择题.png
├── 错题本/                    ← 做错的题（直接按题型分一层，不用翻年份）
│   └── {题型}/
│       └── {年份}{城区}{考试类型}_{题号}.png   例：错题本/函数导数/2022朝阳期末_19.png
└── 计划库/                    ← 每周总结
    └── 周报-{起YYYYMMDD}-{止YYYYMMDD}.md
```

- 题型共 9 类：选择题、填空题、三角函数、立体几何、概率统计、数列、解析几何、函数导数、新定义题。
- **源 PDF 不保留**：上传的 PDF 只作为切片的临时输入，确认后即删除，存档对象是切片图片。
- 文件名里只有题型，**不含知识点** —— 所以改知识点不会导致文件改名，你可以放心在软件里改。

其它目录（一般不用管）：

| 目录 | 作用 |
|------|------|
| `storage/app.db` | 数据库（所有标注、统计的源头）。**想整体备份就备份 archive/ 和这个文件** |
| `storage/crops/` | 切片中间态。已归档的会自动清走，只剩还没打标的错题 |
| `storage/uploads/` | 上传的源 PDF 临时存放处，确认后自动删除 |
| `data/kp_math.json` | 预置知识点树（10 大类 / 96 叶子），可直接编辑 |
| `data/qtypes_math.json` | 9 类题型的定义 |

## 五、其余四个页面

| 页面 | 能做什么 |
|------|---------|
| **错题本** | 看所有错题。可按知识点/题型/城区/考试类型/年份/日期筛选，点卡片看大图（含主次知识点和归档路径）。**大图下方有「🗑 删除此题」**。 |
| **题库** | 看所有做对的题，筛选方式同上，同样可以删题。 |
| **气泡图** | 每个知识点一个气泡，**大小 = 做过几道**，**颜色 = 错误率**（绿→黄→红，灰 = 还没做过）。点气泡看该知识点的错题。右上角「数据表」可以把同样的数字摊成表格看。 |
| **周报** | 近 7/14/30 天做了哪些知识点、哪里错得多、下周建议练什么题型。内容同时写进 `archive/数学/计划库/` 的 md 文件，界面显示的就是那份文件的原文。 |

统计口径：**每题只按「主知识点」计一次**，次知识点只在题目详情里展示、不参与任何统计。

## 六、常见问题

**Q：上传后提示有的题「未定位」，怎么办？**
多半是原卷题号不到 22（比如期末卷常是 21 题）。不影响使用，那道题不会出图，
确认后它也不会进任何库。真的漏切了，目前需要重新上传。

**Q：识别到一半报错停了？**
按弹窗提示处理：额度不足就去充值，Key 无效就改 `.env` 里的 `VLM_API_KEY` 后**重启软件**，
然后点「重试识别」。已经识别好的题不会重做，也不会重复扣费。

**Q：AI 判的知识点不对？**
直接在卡片上改下拉即可，改完立刻重新归档。也可以先不配 key，纯手动选。

**Q：错题本里的数字比我在复核页点错的少？**
错题要**知道题型**才能归档。只点了红框、还没选题型的题会一直留在
`storage/crops/` 里，不进错题本。补上题型即可。

**Q：想删掉一道题怎么办？**
在「错题本」或「题库」里点开那道题的大图，右下角有「🗑 删除此题」，会再问你一次
（弹窗里写清了是哪套卷的哪一题）。确认后：它的切片图片文件会从 `archive/` 里删掉，
错题本/题库/首页汇总的数字立即更新，气泡图和周报下次打开时自动重算。
**删除无法恢复**，删之前想留个底就从 `archive/` 里先把那张 PNG 拷走。

**Q：整卷传错了（选错城区/传错文件）怎么办？**
到「上传」页下方的「📊 已上传的卷子」，把鼠标移到那一行卷子上，右边会出现 **🗑**，
点它 → 确认，整套卷（连同它的全部小题和切片图片）就会被清掉。弹窗会先告诉你
这是哪套卷、多少题、多少错题。**同样无法恢复**。

**Q：能加英语/物理吗？**
数据结构已按科目预留，但第一版只有数学。
